# skill PI Informatika Gunadarma

Panduan kerja untuk menulis dan memeriksa Penulisan Ilmiah Prodi Informatika Universitas Gunadarma berdasarkan Buku Pedoman Penulisan Ilmiah 2025.

Baca [SKILL.md](SKILL.md) untuk aturan dan alur pemeriksaan. [Referensi contoh dan lampiran](references/contoh-dan-lampiran.md) mencatat bentuk PI, contoh dalam pedoman, serta perbedaan antara contoh dan ketentuan. Rujukan halaman menggunakan nomor PDF dan nomor halaman tercetak.

## Pemakaian

Untuk Hermes Agent, salin `SKILL.md` dan folder `references/` ke `~/.hermes/skills/productivity/pedoman-pi-informatika-gunadarma-2025/`, lalu mulai sesi baru. Saat memeriksa naskah, sediakan juga PDF pedoman asli dan dokumen PI yang akan diperiksa. Skill ini tidak menyertakan PDF atau transkripsi lengkapnya.

## Batasan

Pedoman 2025 memiliki beberapa ketentuan yang tidak selaras, antara lain kapitalisasi subbagian, susunan berkas penyerahan, dan format berkas yang diminta pada tahap berbeda. Skill mencatat kedua sisi beserta halamannya, bukan menganggap salah satu otomatis gugur. Pastikan aturan administratif yang berlaku saat mendaftar sidang atau menyerahkan naskah langsung ke Prodi Informatika.

Repo ini bukan terbitan resmi Universitas Gunadarma. Sumber primer tetap [halaman pedoman Prodi Informatika](https://fti.gunadarma.ac.id/informatika/?page_id=563) dan PDF resmi yang berlaku.
